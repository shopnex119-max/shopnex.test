# حالة SHOPNEX ULTIMATE

## حالة الإصدار والموقع

- رابط الموقع العام الدائم: [shopnex119-max.github.io/shopnex.test](https://shopnex119-max.github.io/shopnex.test/).
- الاستضافة الحالية GitHub Pages لمعاينة **واجهة ثابتة**. لا ترتبط بقاعدة بيانات ولا تحفظ عمليات زوار الموقع. فواتير ومشتريات المعاينة محاكاة محلية داخل الصفحة.
- `main` هو الإصدار المنشور الحالي؛ هذه الدفعة في `feature/purchasing-accounting-analytics-zatca-qr` ولا تُعد منشورة حتى دمجها ونشر Pages.
- هذا المستودع يحتفظ بتاريخه؛ لا حاجة لحذف المشروع أو إعادة إنشاء المستودع.

## ما أُضيف في دفعة المالية

- **المشتريات والموردون:** إنشاء الموردين وفواتير الموردين، استقبال كامل للأصناف، تحديث الكمية ومتوسط التكلفة المرجّح، حفظ لقطة السعر/الضريبة والمورد، وتسجيل حركة المخزون للمستخدم.
- **الدفعات:** دفعة أولى ودفعات جزئية/كاملة، حد يمنع تجاوز الرصيد، قيود دفع مستقلة، ومفتاح idempotency يمنع تكرار الدفعة أو إعادة استخدام المفتاح بمحتوى مختلف.
- **المحاسبة:** دليل حسابات أساسي يُهيّأ عند الطلب؛ القيود المنشأة للبيع والشراء والاستلام والدفع والرصيد الافتتاحي متوازنة ومدرجة بالمصدر، مع ميزان مراجعة وقيود وأستاذ وذمم عملاء وموردين.
- **الضريبة:** تصنيف قياسي/صفري/معفى/خارج نطاق الضريبة، أسباب عند اشتراطها، نسخ قواعد بتاريخ النفاذ، ومنع تداخل قاعدة فعالة مع قاعدة أخرى للتصنيف/المعدل نفسيهما. تحفظ رموز وإصدارات القواعد على بنود المستند.
- **التقارير:** ملخص مبيعات ومشتريات ومدفوعات وذمم وضريبة ومدى ربح إجمالي ومخزون، اتجاهات يومية وأفضل منتجات/موردين، تطبيق فترات بتاريخ السعودية (`Asia/Riyadh`)، وتصدير CSV عربي UTF-8 BOM يشمل صفوف التحليل.
- **الدقة:** مصادر حسابات البيع والشراء من API؛ مبالغ `Decimal` وتقريب نصف لأعلى في الخادم، وتمثيل ثابت بالهللات (`BigInt`) للمعاينة المالية في الواجهة. استُخدم المتوسط المرجّح لتكلفة الوحدات المستلمة.
- **QR زاتكا:** مولّد TLV UTF-8/Base64 محلي من 5 وسوم QR الأساسية، ويعرض QR الفاتورة والقيم والوسوم. هذا **تنسيق معاينة Phase 1 فقط**، لا يتصل بزاتكا ولا يرسل الفاتورة ولا يثبت امتثال Phase 2.
- **الواجهة:** صفحات عربية/إنجليزية للمشتريات والمحاسبة والتحليلات وQR، وحقل تكلفة افتتاحية وتصنيف ضريبي في الكتالوج، مع رسوم وتحميل كسول لحزمة التقارير.

## التحقق المحلي

- `services/api/.venv/bin/python -m pytest -q` — **16 اختبارًا ناجحًا**؛ تحذير deprecation واحد صادر عن Starlette/AnyIO.
- `pnpm --dir apps/desktop check` — ناجح.
- `pnpm --dir apps/desktop build` — ناجح دون تحذير حجم: الملف الأساسي نحو 229 KB، وReact نحو 223 KB، والرسوم في حزمة مؤجلة مستقلة.
- `DATABASE_URL=sqlite:////tmp/shopnex-finance-migration.db .venv/bin/alembic upgrade head` — ترحيل كامل ناجح على SQLite مؤقتة فارغة.
- فحص مرئي للواجهة العربية الداكنة: شاشة المشتريات، ميزان المراجعة، ولوحة الرسوم والتقارير.
- الترحيل `4b7e21c60a93` يضيف الجداول والحقول الجديدة. لا ينشئ تفاصيل فواتير أو مدفوعات أو تكلفة تاريخية لم تكن محفوظة من قبل؛ أرصدة الفواتير القديمة لا تصبح تلقائيًا قيودًا محاسبية مُرحّلة.

## ما لا تغطيه هذه الدفعة

- الموقع العام **ليس نظام SaaS إنتاجيًا ذا قاعدة بيانات سحابية**. لتشغيل منشأتك على الويب يجب استضافة FastAPI وقاعدة PostgreSQL بشكل آمن، ضبط HTTPS والنسخ الاحتياطية والأسرار، وربط الواجهة بنطاق API موثوق. إلى ذلك الحين استخدم API محليًا وتأكد من النسخ الاحتياطي.
- شاشة المشتريات ترحّل فاتورة بعد استلام الأصناف كاملة؛ لا توجد أوامر شراء/عروض سعر/استلام جزئي/مرتجعات مشتريات/إشعار دائن أو تطبيق فعلي لحد ائتمان المورد.
- لا توجد إدارة مصروفات متكاملة أو رواتب أو إغلاق فترات/ورديات، تسوية بنكية، عكس قيود مقيّد بالصلاحيات، ميزانيات، مراكز تكلفة أو مراجع محاسبية قانونية.
- سجل فواتير البيع الحالية لا يملك تاريخ استحقاق مستقلًا أو تسجيل دفعات لاحقة؛ أعمار العملاء «أيام مفتوحة» من تاريخ الفاتورة. تقرير VAT تقديري فقط ولا يأخذ في الحسبان كل شروط قابلية خصم ضريبة المدخلات.
- لا يوجد عزل كامل متعدد الشركات والفروع/المخازن والأدوار الدقيقة أو اختبار ضغط/أمن/استعادة قبل الإنتاج.
- لا توجد تكاملات POS hardware أو عمل دون اتصال ومزامنة أو وصول الضيف إلى API.
- **مرحلة 2 لزاتكا غير مكتملة:** لا UBL XML مختوم، ولا CSID أو توقيع/سلسلة تجزئة/وسوم TLV 6–9، ولا Reporting/Clearance، ولا SDK رسمي أو Sandbox للمكلف، ولا تقديم/قبول/اعتماد.
- لم تُنفذ مواصفة المشروع الكاملة ذات الوحدات العديدة؛ هذا تحديث وظيفي تأسيسي وليس ادعاء جاهزية «أفضل برنامج في العالم» أو جاهزية تشغيل مؤسسي.
