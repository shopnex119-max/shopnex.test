# حالة SHOPNEX ULTIMATE

## الحالة المنشورة

- نُشر مصدر النسخة **0.3.0** إلى الفرع الافتراضي `main` عبر دمج [طلب المراجعة #2](https://github.com/shopnex119-max/shopnex.test/pull/2)، merge commit `50f3235d`.
- نجح فحص CI، ثم نجح نشر Pages `37308646362`؛ تحقق HTTP من الرابط العام `200` ومن ملفات JS/CSS الجديدة، وتأكد وجود صفحات المشتريات والمحاسبة والتحليلات ووسم QR.
- الموقع الدائم: [SHOPNEX — GitHub Pages](https://shopnex119-max.github.io/shopnex.test/).
- الاستضافة GitHub Pages ثابتة؛ كل الفواتير والمشتريات المعروضة هناك أمثلة تجريبية في المتصفح ولا تُحفظ. شاشات الكاشير والفواتير وزاتكا مقفلة في المعاينة العامة، وموجز الفواتير مخفي من لوحة البداية، ولا يعرض الموقع نموذج كلمة مرور لعدم وجود خادم تحقق. الـAPI الجديد يعمل مع قاعدة التطبيق المحلية فقط. لا تستخدم الموقع العام لتسجيل معاملات منشأة فعلية.
- حزمة Windows المتاحة هي الإصدار التجريبي `v0.2.0`؛ لم تُبنَ أو تُنشر حزمة سطح مكتب 0.3.0 بهذه الدفعة.

## ما يتيحه مصدر 0.3.0 محليًا

- **المشتريات والموردون:** إنشاء الموردين وفواتير المورد، استلام كامل للأصناف، تحديث الكمية ومتوسط التكلفة المرجّح، حفظ لقطة السعر/الضريبة/المورد، وحركة مخزون مرتبطة بالمستخدم.
- **الدفعات:** دفعة أولى ودفعات جزئية/كاملة، منع تجاوز الرصيد، قيد منفصل، ومفتاح idempotency لمنع تكرار الدفع أو إعادة المفتاح بمحتوى مختلف.
- **المحاسبة:** دليل حسابات أولي عند الحاجة؛ القيود المنشأة للبيع والشراء والاستلام والدفع والرصيد الافتتاحي متوازنة ومسنودة بالمصدر، مع ميزان مراجعة ودفتر أستاذ وذمم عملاء وموردين.
- **الضريبة:** فئات قياسي/صفري/معفى/خارج النطاق، أسباب عند اشتراطها، نسخ مؤرخة للقواعد ومنع التداخل وحفظ نسخة الضريبة على البند.
- **التقارير:** مبيعات ومشتريات ومدفوعات وذمم وVAT تقديري وتكلفة وربح إجمالي ومخزون، اتجاهات يومية وأفضل منتجات وموردين، فترات بتوقيت `Asia/Riyadh`، وتصدير CSV عربي.
- **الدقة:** الخادم مصدر السعر والخصم والضريبة والمخزون. تستخدم العمليات `Decimal` وتقريب نصف لأعلى؛ تستخدم معاينة المال الأمامية عددًا صحيحًا من الهللات (`BigInt`).
- **QR زاتكا:** معاينة TLV UTF-8/Base64 محلية من الوسوم الأساسية 1–5؛ لا اتصال خارجي ولا إرسال ولا ادعاء امتثال Phase 2.
- **قفل الفواتير وزاتكا:** يتطلب فتح الكاشير وسجل الفواتير وزاتكا إعادة تحقق بكلمة مرور حساب SHOPNEX المحلي. يتحقق API من بيانات الحساب، وكلمات المرور لا تُحفظ في الواجهة. معاينة Pages لا تقبل كلمات مرور؛ لعدم وجود خادم آمن تقفل هذه الصفحات فيها.
- شاشات RTL/LTR عربية/إنجليزية، رسوم مؤجلة التحميل، وتحديث مظهر الواجهات المالية.

## نتائج التحقق

- CI على GitHub: فحوص API والواجهة نجحت قبل الدمج. نشر Pages اكتمل بنجاح.
- `services/api/.venv/bin/python -m pytest -q` — **17 اختبارًا ناجحًا**؛ تحذير deprecation واحد من Starlette/AnyIO.
- `pnpm --dir apps/desktop check` و`pnpm --dir apps/desktop build` — ناجحان. الملف الأساسي نحو 229 KB، وReact نحو 223 KB، والرسوم في حزمة مستقلة.
- Alembic `upgrade head` — نجح على قاعدة SQLite جديدة، واختُبر من قاعدة قبل الترحيل تحتوي فاتورة وبندًا ودفعة وحركة مخزون؛ بقيت السجلات القديمة والإجمالي محفوظة. لا يخترع الترحيل تكلفة أو تفاصيل/قيودًا تاريخية لم تكن مخزنة.
- فحص مرئي للشاشات العربية الداكنة: المشتريات، ميزان المراجعة، لوحة التقارير، وسجل/QR التوضيحي.

## ما لا تغطيه هذه الدفعة

- الموقع العام **ليس SaaS ذا قاعدة بيانات سحابية**. يلزم قبل معاملات الويب نشر API وقاعدة PostgreSQL بأمان وربط نطاق وHTTPS وإعداد أسرار ونسخ احتياطي واستعادة. حتى ذلك الوقت API محلية فقط.
- المشتريات تشمل تسجيل فاتورة واستلام كامل؛ لا أوامر شراء أو RFQ أو استلام جزئي أو مرتجعات/إشعار دائن أو حد ائتمان مورّد.
- لا دفعات لاحقة لفواتير العملاء أو تاريخ استحقاق مستقل لها؛ لا مصروفات وأصول وتسويات بنكية وإغلاق فترات/ورديات ومراكز تكلفة ومراجعة محاسب قانوني.
- التقرير الضريبي والهامش **تقديريّان** من البيانات المسجلة؛ ليسا إقرارًا رسميًا أو صافي ربح بعد كل المصروفات. لا تُنشأ قيود تاريخية تخمينية.
- لا عزل كامل متعدد الشركات والفروع/المخازن أو أدوار دقيقة واختبار ضغط/اختراق/استعادة على نشر إنتاجي.
- لا بث حي للمطبخ أو تكاملات أجهزة وطابعات أو عمل دون اتصال ومزامنة أو وصول الضيف إلى API.
- **Phase 2 لزاتكا غير منفّذة:** لا XML UBL مختوم، ولا CSID أو توقيع/تجزئة/وسوم TLV 6–9، ولا Reporting/Clearance، ولا SDK رسمي/Sandbox لحساب المكلف أو تقديم/قبول.
- لا تمثل هذه الدفعة تنفيذ المواصفة الكاملة أو جاهزية مؤسسية أو عبارة «أفضل برنامج في العالم».
